# Portfolio Premium Aghisni Binurilhaq

Website portfolio pribadi yang dibuat menggunakan HTML5, CSS3, dan JavaScript vanilla. Desain dibuat dengan nuansa premium, modern, dark mode, glassmorphism, dan animasi halus.

## Fitur utama
- Landing page premium dan responsif
- Hero section dengan typing animation
- Custom cursor dan mouse glow
- Reveal animation dengan Intersection Observer
- Project filtering
- Timeline experience, skills, certificates, contact
- SEO dan aksesibilitas dasar

## Cara menjalankan
1. Buka folder portfolio.
2. Jalankan file index.html dengan browser langsung, atau gunakan live server jika Anda memakai VS Code.

## Cara mengganti foto
- Ganti file [assets/profile.jpg](assets/profile.jpg) dengan foto yang lebih representatif.
- Pastikan nama file tetap profile.jpg.

## Cara mengganti project
- Buka [index.html](index.html).
- Temukan bagian Projects.
- Ubah teks, gambar, dan link sesuai project Anda.

## Deploy ke GitHub Pages
1. Buat repository GitHub.
2. Upload seluruh isi folder portfolio ke repository.
3. Buka Settings > Pages.
4. Pilih branch main dan folder root.
5. Simpan dan tunggu proses deployment.

## Deploy ke Netlify
1. Buka Netlify.
2. Drag and drop folder portfolio ke dashboard.
3. Atau hubungkan repository GitHub.
4. Pilih publish directory sebagai root folder.

## Deploy ke Vercel
1. Buat project di Vercel.
2. Hubungkan repository.
3. Vercel akan mendeteksi static website secara otomatis.
4. Deploy proyek Anda.
